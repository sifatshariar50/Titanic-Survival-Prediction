# Titanic-Survival-Prediction
Titanic passenger survival prediction using python and machine learning
Titanic Survival Prediction

Project Overview

This project explores the Titanic passenger dataset and uses machine learning to predict whether a passenger survived the Titanic disaster.

The project demonstrates data preprocessing, exploratory data analysis, feature engineering, model training, and evaluation using Python.

Objectives

Explore passenger demographics and travel information.

Identify and handle missing values.

Analyze factors associated with passenger survival.

Prepare categorical and numerical features for machine learning.

Train a classification model to predict survival.

Evaluate model performance using appropriate metrics.

Dataset

The project uses the Titanic dataset from Kaggle.

Source: Kaggle Titanic Competition

Common features include:

Pclass — Passenger class

Sex — Passenger sex

Age — Passenger age

SibSp — Number of siblings or spouses aboard

Parch — Number of parents or children aboard

Fare — Ticket fare

Embarked — Port of embarkation

Survived — Survival target (0 = No, 1 = Yes)
